# Demonstration asset provenance

The four `public/demo-*.svg` illustrations and `public/favicon.svg` were drawn directly as SVG code for this project. They contain no stock photography, third-party artwork, embedded fonts, real people, or identifiable real properties. They are original project assets intended for use with this demonstration. All garden illustrations are visibly labeled as placeholders on the page.

The legacy placeholder photographs and unused public icon sprite had no recorded source or license in this checkout. They were removed from `public` so Vite cannot copy them into the demonstration deployment.

The existing typography is preserved using Google Fonts' hosted stylesheet. DM Sans and Playfair Display are available under the SIL Open Font License 1.1; the font binaries are served by Google Fonts rather than bundled into this project. Upstream license records:

- [DM Sans license](https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt)
- [Playfair Display license](https://github.com/google/fonts/blob/main/ofl/playfairdisplay/OFL.txt)
- [Google Fonts usage information](https://developers.google.com/fonts)

The only contact details displayed by the site are a fictional 555 phone number, a reserved `.example` email address, and a street-address placeholder. No personal contact details are used.
